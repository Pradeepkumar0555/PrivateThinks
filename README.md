## ✨ Features

### 🌅 Good Morning (`index.html`)
- **Theme**: Soft blush pink, rose quartz, and warm sunrise golden gradients.
- **Particles**: Drifting hearts, falling sakura/rose petals, and twinkling stars.
- **Chime**: Bright morning harp chime synthesized using native Web Audio API.
- **Message**: Sweet, uplifting message customized for starting her morning with a smile.
- **Surprise**: Secret unfolded love letter + confetti burst.

### 🌙 Good Night (`night.html`)
- **Theme**: Deep midnight navy, royal indigo, lavender frost, and glowing golden moonbeams.
- **Particles**: Twinkling stars, gentle floating fireflies, and shooting meteors.
- **Chime**: Dreamy, soothing music-box lullaby synthesized using native Web Audio API.
- **Message**: Peaceful, caring message wishing her relaxing sleep and sweet dreams.
- **Surprise**: Cozy night whisper note + glowing stardust burst.

## 💌 How to Personalize

You can customize both pages in two ways:

### Option 1: URL Parameters (Instant Sharing)
- `?name=` or `?her=` : Her name / pet name (e.g. `Beta`, `Mera Bacha`, `jaan`)
- `?from=` or `?me=` : Your name / signoff (e.g. `Pradeep`, `Yours Always`)
- `?msg=` : Custom message
- `?surprise=` : Custom surprise note

### Option 2: Edit `CONFIG` in Code
- Morning config: Open `index.html` and edit `const CONFIG = { ... }`
- Night config: Open `night.html` and edit `const CONFIG = { ... }`

## 🚀 How to Host on GitHub Pages

1. Commit and push:
   ```bash
   git add .
   git commit -m "Add Morning and Good Night web pages"
   git push origin main
   ```
2. In GitHub **Settings** > **Pages** > Select branch `main` and root `/` > Click **Save**.
3. Both pages are immediately available online!
